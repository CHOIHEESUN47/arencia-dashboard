Meta 보고서 파일 업로드

Meta 광고 관리자에서 내보낸 CSV 또는 Excel(.xlsx/.xls) 보고서 파일을 업로드하면 컬럼을 자동으로 분석해 Supabase 테이블에 저장(UPSERT)합니다. 조회는 누구나 가능하지만, 저장은 로그인한 팀원만 가능합니다 — "Supabase에 저장" 버튼을 누르면 로그인 창이 뜹니다.

1. 리포트 종류 선택
2. 파일 선택 (.csv / .xlsx / .xls)

3. 컬럼 매핑 확인

파일에서 감지한 컬럼명을 자동으로 추정해 연결했습니다. 다르면 직접 선택해 주세요.

4. 미리보기 (상위 15행)
데이터 출처: Supabase 테이블(캠페인) · 테이블(소재) (Meta Ads API로 수집) · Hook Rate = 3초 동영상 재생수 ÷ 노출수, Hold Rate = ThruPlay 건수 ÷ 3초 동영상 재생수 (소재 탭은 3초 동영상 재생수 데이터가 없어 “–”로 표시) · 페이지를 새로고침하면 Supabase의 최신 데이터를 다시 불러옵니다.
